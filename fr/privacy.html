Politique de confidentialité

Dernière mise à jour : 2 octobre 2026

Bivouac est une application Android de préparation et de suivi de randonnées sur plusieurs jours, publiée par Sébastien Raison. Cette politique s'applique à toutes les versions de l'application, qu'elle ait été installée depuis Google Play, F-Droid ou GitHub.

En bref

Bivouac ne collecte aucune donnée personnelle. Il n'y a ni compte, ni serveur géré par le développeur, ni publicité, ni statistiques d'usage, ni rapport de plantage. Tout ce que vous confiez à l'application reste sur votre appareil.

Bivouac est un logiciel libre (GPL-3.0). Son code source est public, chaque affirmation de cette page est donc vérifiable : github.com/sebastienraison/Bivouac.

Données stockées sur votre appareil

Bivouac enregistre dans son espace privé, que les autres applications ne peuvent pas lire :

  • les traces GPX que vous importez, ainsi que les bivouacs et les étapes que vous planifiez
  • votre Journal : randos réalisées, notes, tags et statistiques
  • une copie des photos que vous attachez à une rando, avec la position GPS et la date qu'elles contiennent
  • vos réglages

Rien de tout cela n'est envoyé au développeur, ni à qui que ce soit.

Votre position

Bivouac n'accède pas à la position de votre appareil. L'application n'a aucune permission de localisation.

Les seules positions qu'elle manipule sont celles des fichiers que vous lui confiez : les points d'une trace GPX, et la position GPS enregistrée dans une photo.

Connexions réseau

Bivouac se connecte à Internet pour une seule raison : télécharger les tuiles de carte. Ces connexions sont en HTTPS. Elles vont directement de votre appareil au fournisseur de cartes, jamais par le développeur.

Les tuiles téléchargées sont conservées dans un cache sur votre appareil, ce qui réduit les requêtes suivantes.

Le bouton météo ouvre le site Meteoblue dans votre navigateur, pour des coordonnées arrondies à deux décimales (environ un kilomètre). Rien n'est envoyé tant que vous n'appuyez pas sur ce bouton. À partir de là, c'est la politique du site Meteoblue qui s'applique.

Esri et Meteoblue sont des services non libres. Un seul interrupteur dans les Réglages, « Désactiver les fonctions non libres », coupe les deux.

Ces services sont gérés par des tiers et ont leur propre politique de confidentialité : OpenTopoMap, OpenStreetMap, Esri, Meteoblue.

Les permissions photo ne sont demandées que lorsque vous utilisez la fonction photos. Cette fonction peut être entièrement désactivée dans les Réglages : l'accès à la galerie n'est alors jamais demandé.

Sauvegardes

  • La sauvegarde de Bivouac. Depuis les Réglages, vous pouvez exporter toutes vos données dans un fichier. Vous choisissez sa destination. Ce fichier vous appartient : Bivouac n'en garde aucune copie ailleurs.
  • La sauvegarde Android. Si la sauvegarde est activée sur votre appareil, Android peut inclure les données de Bivouac, photos exclues, dans la sauvegarde stockée sur votre compte Google. C'est une fonction d'Android, qui se règle dans les paramètres de votre appareil. Voir la documentation de Google.

Sécurité

Vos données sont enregistrées dans l'espace privé de l'application, protégé par Android : les autres applications n'y ont pas accès. Les connexions vers les fournisseurs de cartes sont chiffrées. Aucune donnée n'est transmise au développeur : il n'en existe donc aucune copie ailleurs que sur votre appareil et dans vos propres sauvegardes. Le fichier de sauvegarde que vous exportez n'est pas chiffré, conservez-le en lieu sûr.

Durée de conservation et suppression

Vos données restent sur votre appareil jusqu'à ce que vous les supprimiez. Vous pouvez :

  • supprimer une trace, une rando ou une photo depuis l'application
  • effacer les données de l'application depuis les paramètres Android
  • désinstaller l'application, ce qui supprime tout ce qu'elle a enregistré sur l'appareil

Si la sauvegarde Android est activée, une copie peut subsister sur votre compte Google. Elle se gère depuis les paramètres de sauvegarde de votre appareil.

Le développeur ne détient aucune de vos données : il n'a donc rien à supprimer de son côté.

Ce site

Cette page et le site bivouac.rseb.net sont hébergés par GitHub Pages. Comme tout hébergeur, GitHub enregistre l'adresse IP des visiteurs, pour des raisons de sécurité. Ce traitement est régi par la déclaration de confidentialité de GitHub, et non par la présente politique, qui porte sur l'application.
